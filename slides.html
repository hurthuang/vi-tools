→ 文字轉點字

功能

  • 中、英文字混合文本轉譯
  • 英文可選：UEB G1／G2／自訂規則／電腦點字
  • UEB 自訂：可選擇啟用哪些縮寫規則，適合依教學進度分批開放
  • 自訂轉譯規則：針對特殊例外設定（如特定地名不縮寫）
  • 低年級模式：字間加空方、標點後加空行
  • 雙視校對：點擊注音格可手動修正破音字讀音
  • 標示縮寫字：快速查找套用縮寫規則的字

適用情境

  • 老師輸入考卷或作業文字，直接輸出點字版
  • UEB 教學：只啟用已教過的規則，未教的以一級呈現
  • 中英文混排教材一次轉換
  • 需要處理破音字的文件
  • 低年級點字教材製作
特教老師 視巡老師 UEB 教學

← 點字轉文字

功能

  • 中、英文點字混合文本一次還原為文字
  • 中文使用智慧選字引擎，正確還原同音字
  • 格式調整：可將斷行的點字接回再轉換
  • 逐格雙視對照：點字在上、國字在下
  • 點擊國字格可手動修正同音異字
  • 修正紀錄自動存檔，可匯出校對檔跨裝置繼續

適用情境

  • 收到學生點字作答，還原為文字批改
  • 校對點字書轉換結果
  • 老師練習閱讀點字，對照國字確認
  • 驗證文字→點字能否完整還原

適用情境

  • 學生確認 Nemeth 符號寫法
  • 輸入數學點字反查對應數學式

🔊 語音字典切換 (DictSwitcher)

NVDA + Alt + D循環切換語音字典

切換順序

  1. 破音字修正
  2. 注音點字
  3. 數學點字
  4. 停用自訂字典

各字典說明

  • 破音字修正：修正語音引擎對破音字的錯誤讀音（如「行人」vs「銀行」）
  • 注音點字：依注音點字規格調整語音報讀，與「報點」附加元件作用相同
  • 數學點字：讓語音引擎正確朗讀 Nemeth 數學符號
  • 停用：還原 NVDA 預設語音字典

📖 國語字典查詢 (zhDict)

Alt + NVDA + K基本查詢
Alt + Shift + NVDA + K豐富查詢（含例句、同反義詞）

選取或複製字詞後按快捷鍵，自動偵測中英文並切換對應字典

中文　教育部重編國語辭典
  • 注音符號、詞性
  • 釋義、例句
  • 似義詞
英文　Free Dictionary ＋ Google 翻譯
  • 音標、詞性
  • 中文釋義、英文例句
  • 同義詞、反義詞

📤 點字輸出匯出 (brailleExport)

NVDA + Shift + C快照目前點字顯示畫面
NVDA + Shift + R開始錄製（再按一次停止並輸出）

輸出格式

  • 複製到剪貼簿（預設）
  • 儲存為 .txt（Unicode 點字）
  • 儲存為 .brf（BRF ASCII，供印表機使用）

可設定項目

  • 匯出目錄（預設為桌面）
  • 每行格數（依點字印表機紙張寬度）
  • 檔名加入時間戳記，避免覆蓋舊檔

適用情境

  • 擷取學生點字作答，匯入「點字轉文字」還原
  • 製作教材時驗證點字輸出正確性
  • 輸出 BRF 供點字印表機列印
  • 快速記錄點字顯示器上的內容

國語字典查詢 (zhDict)

快捷鍵

  • Alt + NVDA + K：基本查詢
  • Alt + Shift + NVDA + K：豐富查詢（含例句、同反義詞）

選取或複製字詞後按快捷鍵，自動偵測中英文並切換對應字典。

中文：教育部重編國語辭典

  • 注音符號、詞性
  • 釋義、例句
  • 似義詞

英文：Free Dictionary ＋ Google 翻譯

  • 音標、詞性
  • 中文釋義、英文例句
  • 同義詞、反義詞
第 14 頁

點字輸出匯出 (brailleExport)

快捷鍵

  • NVDA + Shift + C：快照目前點字顯示畫面
  • NVDA + Shift + R：開始錄製（再按一次停止並輸出）

輸出格式

  • 複製到剪貼簿（預設）
  • 儲存為 .txt（Unicode 點字）
  • 儲存為 .brf（BRF ASCII，供印表機使用）

可設定項目

  • 匯出目錄（預設為桌面）
  • 每行格數（依點字印表機紙張寬度）
  • 檔名加入時間戳記，避免覆蓋舊檔

適用情境

  • 擷取學生點字作答，匯入「點字轉文字」還原
  • 製作教材時驗證點字輸出正確性
  • 輸出 BRF 供點字印表機列印
  • 快速記錄點字顯示器上的內容
