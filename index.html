視障輔助工具集

為視覺障礙教育設計的點字轉換、教材製作與學習工具，分成四組。
上方第一排選組別，第二排選該組的工具；也可以直接點下面的卡片。

點字轉換

文字、數學、樂譜和點字互相轉換。

→
文字轉點字 UEB
將中文或英文文字即時轉換為 UEB 統一英文點字，支援 G1／G2 縮寫與 Comp8 電腦點字模式， 並提供雙視校對視圖，可逐字確認轉譯結果。
›
←
點字轉文字 UEB + 注音
輸入 UEB G2 縮寫點字或台灣注音點字，即時還原為英文或中文， 並提供逐格對照視圖，可直接在格子上手動修正同音異字。 注音點字引擎使用 McBopomofoWeb。
›
π
數學點字 Nemeth 2022
雙向轉換 LaTeX 數學式與 Nemeth 點字，支援分數、根號、上下標、矩陣等結構， 並提供即時 MathJax 預覽與數學式編輯器。
›
♪
音樂點字 BANA 2015
ABC 記譜或 MusicXML 與點字樂譜（BANA Music Braille Code 2015）雙向轉換，支援單音、鋼琴雙手、和弦、 歌詞（國語點字）與和弦名稱；五線譜預覽、點字對照、播放與逐音報讀。
›

教材製作

把文件和圖形整理成視障學生可以用的教材。

📄
文件整理 TTS
將 PDF 或其他文件轉換為乾淨的純文字，去除頁首頁尾與排版雜訊， 適合語音報讀軟體使用。內建 TTS 語音預覽，可直接在瀏覽器中試聽。
›
✋
觸摸圖 測試版
從試題 PDF、Word 或截圖框選圖形，轉成 ViewPlus Tiger 點字印表機的 .prn 觸摸圖：線條自動整理成一點寬、 A、B、C 等標籤轉成點字並避開線條、網底轉成填色；可再用畫筆、形狀與填色修改。
›

學習與查詢

點字規則查詢、教材與學生練習。

📚
點字教材 4 本
台灣注音點字規則整理（聲韻調、標點符號）、數理點字教材（Nemeth，108 課綱國小到高中、化學、物理）、UEB 學習手冊（字母、縮寫、練習與縮寫快速查詢表）、音樂點字（點字樂譜規則對照，附可修改的例子）。 每章每節都是標題，點字可用點顯器摸讀，也可切換 SimBraille 顯示。
›
🧮
珠算練習 Nemeth
給盲生用算盤代替直式的分級練習：依撥珠時要用到的補數分級出題（加、減、乘一位數、兩位數 × 兩位數、除以一位數、兩位數）， 題目用點顯器摸讀，答案用點字鍵或六點鍵盤以 Nemeth 輸入，答錯可再試兩次；老師可先預覽、匯出 .brl 題目，練習結果存成 CSV。 附各級撥珠教法與教學法筆記。
›
🎹
點字樂譜練習 學生版
學生用點字鍵或六點鍵盤打點字樂譜，每打一個音就聽到它；寫好可以播放、存檔、匯出 MusicXML。
›
🔍
UEB 查詢 規則解析
輸入英文單字查詢 G2 點字並逐條說明套用了哪些縮寫規則；或輸入點字反查英文， 以動態規劃列出所有可能的切分方式。結果同步與 liblouis 比對，歧異可一鍵回報。
›
⣿
縮點（實驗性質）
注音點字的調號併入第七、八點，每個字少寫一方；輸入文字對照國語點字和縮點，附讀寫規則與範例。只適用八點點字顯示器；摸讀要搭配 brailleTableSwitcher 1.3.0 以上，打字要搭配豪點輸入法 1.7 以上。
›

NVDA 附加元件

配合點顯器與報讀軟體 NVDA 使用，連結開到 GitHub 頁面（新視窗），在那裡下載與看說明。

點字表切換 (brailleTableSwitcher)
快速切換注音點字、UEB G1／G2 輸出轉譯表
豪點輸入法 (6d-IME)
六點點字鍵盤多模式輸入，支援注音點字、comp8、UEB、Nemeth
語音字典切換 (DictSwitcher)
快速在一般修正、注音點字、數學點字字典間循環切換
國語字典查詢 (zhDict)
選字查詢中文辭典（萌典）或英文字典，自動判斷語言
點字輸出匯出 (brailleExport)
擷取點字顯示器畫面，匯出為 Unicode 點字或 BRF 檔案
光點驅動 (metecBD)
光點點字顯示器 NVDA 驅動附加元件
