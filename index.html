視障輔助工具集
為視覺障礙教育設計的文字處理與點字轉換工具。
部份工具均支援開啟檔案（TXT、DOCX、ODT、RTF、PDF）與格式整理功能。
⠿
點字翻譯 UEB
將中文或英文文字即時轉換為 UEB 統一英文點字，支援 G1／G2 縮寫與 Comp8 電腦點字模式， 並提供雙視校對視圖，可逐字確認轉譯結果。
UEB G1 / G2 / Comp8 中英文混排 雙視校對 自定義縮寫規則 六點鍵盤輸入

📄
PDF 轉視障友善文字 TTS
將 PDF 或其他文件轉換為乾淨的純文字，去除頁首頁尾與排版雜訊， 適合語音報讀軟體使用。內建 TTS 語音預覽，可直接在瀏覽器中試聽。
PDF 萃取 頁首頁尾偵測 格式自動整理 TTS 語音預覽 進階取代
›
⠼
Nemeth 數學點字轉換 Nemeth 2022
雙向轉換 LaTeX 數學式與 Nemeth 點字，支援分數、根號、上下標、矩陣等結構， 並提供即時 MathJax 預覽與數學式編輯器。
LaTeX → Nemeth Nemeth → LaTeX MathJax 預覽 數學式編輯器 六點鍵盤輸入
›
⠠
UEB G2 反向轉換 G2 → 文字
將 UEB G2 縮寫點字反向還原為英文原文，並同步產生 Comp8 電腦點字對照。 支援 ASCII 點字與 Unicode 點字兩種輸入格式，預設六點鍵盤輸入。
G2 → 英文原文 Comp8 對照 ASCII / Unicode 輸入 逐格對照 六點鍵盤預設開啟
›

UEB G2 轉譯查詢 規則解析
輸入英文單字查詢 G2 點字並逐條說明套用了哪些縮寫規則；或輸入點字反查英文， 以動態規劃列出所有可能的切分方式。結果同步與 liblouis 比對，歧異可一鍵回報。
英文 → G2 點字 點字 → 英文 規則逐條解析 liblouis 比對 歧異回報
