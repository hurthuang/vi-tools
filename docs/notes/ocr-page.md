# 文字辨識頁（ocr.html）

2026-11-11 使用者：要一個單獨的 OCR 頁面，開圖檔或貼上剪貼簿的圖，辨識成文字。

- 位置：教材製作組，觸圖製作後面（頁籤、首頁卡片、`frame-ocr`，`data-src`，網址 `#ocr`）；框架加 `allow="clipboard-read; clipboard-write"`（「貼上剪貼簿的圖」按鈕用 Clipboard API）。
- 辨識：`ocr-web.js`（網頁版文字辨識，PP-OCRv6 small int8，Web Worker，見 vtdoc.md）；行的排列沿用 `vtdoc-build.js` 的 `ocrLines`（同一列併起來、兩欄先左後右）。
- 輸入：開啟圖檔（可多選）、拖放、Ctrl+V（paste 事件；焦點在結果文字框時貼文字照常）、按鈕讀剪貼簿。圖長邊超過 2000 縮到 2000（同版面整理掃描頁），小於 1000 放大到 1000（最多 3 倍，低解析度截圖才認得出來）；透明底當白色。
- 「同一段的行接起來」（預設勾）：上下間距 < 0.8 行高、上一行排到最右邊附近（差 8% 以內）、下一行不是題號／選項／條列開頭，就接起來；中文不加空格，英數之間加空格。不看上一行是不是以「。」結尾（中文段落中間的行也常這樣）。
- 「新的結果接在後面」：一頁一頁截圖時用；多張圖時每張前面標「【圖 n】」。
- 輸出：文字框可改、複製、存成「文字辨識.txt」（UTF-8 BOM、CRLF）、在首頁框架裡「送到文字轉點字」（`sendToBt`，同 nc）。
- 測試（2026-11-11）：115 音樂班試題第 2 頁截圖（150 dpi）858 字 9.6 秒，題目接成段落；選項圈號偶爾漏認（③④）。72 dpi 小截圖 2 秒。首頁框架裡送到文字轉點字正常。
- **直書**（2026-11-11 使用者回報：由右而左的直書，結果變成由左而右）：原因是 `ocrLines` 照「同一高度放同一行」排，直書每一欄高度都重疊，整頁變一行、欄由左往右。改成：兩個字以上的字框多數是瘦長直條（高 > 寬 1.3 倍）就是直書，整張圖逆時針轉 90 度（最右邊的欄變成最上面一行）再整頁辨識一次，排列、接段落沿用橫書。試過「一欄一欄排、欄由右往左」，字比較常錯（多字、錯字）；整頁轉的較準。直書時間約兩倍（辨識兩次）。測試圖（國文課本〈飲食文學簡介〉截圖）151 字：順序、段落對；頓號「、」4 個沒認到（直書標點在字的右上角）、「變遷」少一字。
- **算式**（2026-11-11 使用者：沒有辨識套件時也要能單獨辨識一個算式）：「辨識成」文字／算式（localStorage `vi-ocr-mode`）。算式用 `mfr-web.js`（Pix2Text MFR int8，33 MB，跟版面整理同一個）；截圖保持原大小（長邊不到 400 放大到 400，最多 3 倍；超過 2000 縮小），`vitoolsMfr.clean` 灰階、淺色變白。一張圖一行 `\(tex\)`，不加「【圖 n】」；信心 < 0.6 的在狀態列提醒。校對框下面 MathJax 預覽（有 `\(` 的行）。「送到數學點字」：`sendToNc` → index.html 切 `frame-nc`、轉 `setNcInput`（只收同一個網站）→ nemeth_converter.html 切到 l2n、取代 `l2n-in`、`l2nConvert()`。測試：113 複習 3a1 的算式裁圖 3 張＋縮成 1/3 的一張，4 個都對（跟手打答案相同），4 張 6.6 秒（含載入模型）。
- **樂譜**（2026-11-11）：要本機辨識套件（完整版，`/api/omr`，辨識套件分支 `omr-api`、預定 0.4.2）。`haodian-ocr.js`：偵測記下 `found.omr`（`GET /api/ocr` 的 `omr`；桌面版還沒啟動的先當成有），新增 `vitoolsHaodian.omr(dataURL)`。頁面：打開時 `detect({ auto: true })`（這台瀏覽器連上過才找，同版面整理），沒找到顯示「找本機辨識套件」按鈕與「什麼是辨識套件？」；找到而且 `omr` 才出現「樂譜」選項（上次選樂譜的會記住）。**試卷版（2026-11-11 使用者定）**：什麼都不提，跟沒裝一樣（樂譜選項、找辨識套件按鈕、說明連結都收起來）；只有自己按「找本機辨識套件」時狀態列說一次「這個版本沒有樂譜辨識」。桌面版背景啟動後才發現是試卷版的，收起樂譜選項並說明。一張圖送一次，兩個引擎的結果列在校對框下面（`#scores`：聲部、小節、音數、調號、拍號），每個結果「送到音樂點字」「下載 MusicXML」；校對框只寫摘要。送到音樂點字：`sendToMusic` → index.html 切 `frame-music`（還在載入就等 load）→ music/js/app.js 收 `setMusicXml`（只收同一個網站）→ `importMusicXML`，跟開檔一樣（music/index.html 的 `?v=` 改 64）。測試：115 單行旋律截圖，找辨識套件 → 樂譜 → 6 秒兩個結果 → 送到音樂點字匯入成 ABC（homr 版 4/8 拍，提示第 1 小節拍數不符：弱起拍）。
- 沒做：PDF（用版面整理）、手寫、直書夾橫排的英數。
