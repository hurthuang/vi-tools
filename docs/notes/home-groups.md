# 首頁分組（index.html）

2026-10-25 使用者：工具越來越多，卡片太多，改成分組。

- 兩排頁籤：
  - 第一排 `#tabbar`（`aria-label="分組"`）：主頁、點字轉換、教材製作、學習與查詢、說明。
  - 第二排每組一個 `.subbar`（`role="tablist"`，`data-group="group-xxx"`），只顯示目前那一組；主頁、說明沒有第二排。
- 分組：
  - 點字轉換：文字轉點字、點字轉文字、數學點字、點字樂譜轉換（music/index.html）
  - 教材製作：文件整理、觸摸圖
  - 學習與查詢：UEB 查詢、點字樂譜規則（music/rules.html）、點字樂譜練習（music/student.html）、珠算練習、點字教材。順序英文 → 國語 → 音樂 → 數學，縮點對照合併進來時放在 UEB 查詢後面。
- 分組頁籤的 `data-target` 是 `group-xxx`，`resolve()` 換成那組上次用的工具（`localStorage` `vitools-group-last`），沒有就是第一個。網址還是一個工具一個（`#math`、`#abacus`、`#music-rules`、`#music-student`…），分組本身沒有網址；舊連結都照常。
- 方向鍵只在同一排移動（自動切換）；Tab 從第一排到第二排。手機寬度兩排都可以左右捲，切換時目前的頁籤會捲進畫面。
- 首頁：h1 標題，每組一個 h2 加一行說明，底下是該組的卡片（卡片拿掉功能標籤，短一點）；NVDA 附加元件也改成 h2。
- 新的框架（樂譜規則、練習、點字教材）用 `data-src`，第一次打開才載入。
- guide.html：側欄、工具總覽表格、各節順序都照分組；README 工具一節開頭說明分組。
- 合併 zh-tw-short 時：縮點對照放進「學習與查詢」第二排（UEB 查詢後面），首頁卡片放進學習與查詢那一組，從 NVDA 附加元件那一區移出來。
