# 文字轉點字：題號排版、排版後保住中文點字（2026-10-27）

需求來自另一個 session（1027-74）幫使用者手動重排桂林國小 1027 的考卷時整理出來的規則與坑。

## 題號排版（`btLayoutQuestions`，「🔢 題號排版」按鈕）
- 題號統一成「N. 」；缺句點的（`16掙脫`）補成 `16. 掙脫`
- 連續的題號行當成一組，依序找 1、2、3…（下一題號碼要剛好接上，題目裡的數字不會被當成題號）
- 一組裡全部都是語詞題（去掉結尾「。」後沒有標點、空白）：去掉「。」，依序往同一行排，超過每行方數就整題換行，一題不拆兩行
  - 量法：這一行的 `_getLineTokens` 點字格數加總（低年級「字間標點空方」模式先做 `_lgPreprocess`）
- 有句子題（含標點）的組：只把行首題號改成「N. 」，不合併
- 標題行、空行、其他行原樣

## 排版後保住中文點字（`btKeepZhBraille`）
手動修正的 ctxKey 是「前兩字|本字|後一字」，只看同一行；自動讀音（斷詞、多音字規則）也看前後文。
加題號、換行、刪行之後：手動修正對不上（`難走|一|定` → `|一|定`），沒修正的字也可能變（風調雨順的「調」ㄊㄧㄠˊ→ㄉㄧㄠˋ）。
- 排版前用 `_btZhSeq` 記下每個中文字的點字（跟 render 一樣的前處理與斷詞），排版後再算一次
- `_btAlignZh` 逐字對齊（排版可能刪掉抬頭、提示行，往前看 300 字、連續 3 字相同才算重新對上）
- 點字不同的，用新的 ctxKey 補一筆 zhEdit 保留排版前的點字
- 「題號排版」和文字轉點字頁的「📋 格式調整」（`btOpenFormatModal`，套用時）都會做

## 報告（`_btShowLayoutReport`，輸出區上方）
- 前後文相同、排版前卻在不同地方讀音不同的字：一個 ctxKey 只能有一種點字，列出來請使用者確認（例：圈詞檔兩處「樹枝 掙脫」一處 ㄓㄥˋ 一處 ㄓㄥ）
- 同一個語詞在不同題點字不同（題號排版才有）
- 補了哪些修正，附排版後自動判斷的讀音，可按「改用排版後的」：保住的不一定是對的（國卷「傍晚」原本自動判斷 ㄅㄤˋ，排版後是 ㄅㄤ 才對）
- 對不上任何字的手動修正（存檔常帶著其他文件的修正），可一鍵刪除
- 「↩ 復原排版」：還原文字與手動修正

## 驗證
